看懂工作流：從官方資料到互動儀表板

用 Antigravity 串接日本 e-Stat 官方 API，交給 data-analyst 技能清洗，最後在 Data Atoms 做成儀表板。這一頁先帶你看完五個階段。

1 拿到資料2 處理資料3 探索性驗證 (EDA)4 深入洞察與分析方法5 建立互動儀表板

五個階段

1

拿到資料：鎖定權威資料庫與 API 連線

分析的第一步不是下載 CSV，而是定義商業命題，並透過 API 連線取得官方權威數據。今天我們串接日本總務省統計局 e-Stat 官方 API，鎖定 1975 到 2024 半世紀 47 都道府縣面板數據。

  • 在個人 My Page 申請金鑰（appId）。
  • 避坑重點：登錄 URL 務必填寫 http://test.localhost。
  • 調用端點：/getStatsList 取得目錄；/getStatsData 獲取數據。
2

處理資料：調用 data-analyst 技能自動清洗

調用 data-analyst 輕量技能包

內建 4 大 Prompt 樣板與 clean_data.py，一鍵將千分位逗號數值（"14,178,000"）與百分比（23.4%）轉為乾淨數值。

GitHub 倉庫

特徵工程加工：計算關鍵業務指標，如 高齡化率 = 65歲以上人口 / 總人口 與 扶養比。

3

探索性驗證 (EDA)：尋找異常與極值

在動手畫大圖前，先以統計眼光探尋資料的分佈形狀。鎖定 2008 年日本總人口 1.28 億峰值拐點，並對比秋田縣 (39.5%) 與東京都 (22.7%) 的極值剪刀差。

4

深入洞察與分析方法：也可以怎麼做分析

在動手做儀表板前，先釐清業務切角。參考 17 領域研究指南，掌握少子化、高齡化與地方產業的關聯分析法。遵循「現況 ➔ 原因 ➔ 建議」三段論向決策者匯報，並透過 dataviz-motion 一鍵合成 34 秒包豪斯動態數據簡報影片。

查閱 17 領域研究指南
5

建立互動儀表板：Data Atoms 實作（Tableau-like）

弄清楚資料與分析思路後，最後才能做儀表板！進入 data_atoms.html 工作台。隨意將欄位拖曳至 X 軸、Y 軸、顏色與大小編碼槽，切換 10 大數據原子圖表，並透過地區與年份雙層篩選器即時下鑽。
