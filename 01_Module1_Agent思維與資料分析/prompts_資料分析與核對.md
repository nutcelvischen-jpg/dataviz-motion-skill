## 🔹 Prompt 1-1：資料清洗與格式規範化（1,088 家上市企業營收真實資料版）

```markdown
你是一位具備 15 年經驗的資深商業與金融數據工程專家。我已經上傳了一份由臺灣證交所 (TWSE) 彙整的真實市場檔案 `實戰挑戰_臺灣上市公司營收統計_1088家真實髒資料.csv`（共 1,088 家公司）。

請仔細檢查數據結構，並呼叫代碼執行器（Python / Pandas）完成嚴格清洗：

### 執行規則：
1. **去除空白**：去除「公司名稱」、「產業別」等文字欄位的所有前後贅餘空白（Trim Whitespace）。
2. **千分位字串數值化**：
   - 將包含逗號千分位的營收數字（例如 "14,321,556"）強制轉換為純數值 Float / Int。
   - 檢查「營業收入-去年當月營收」，若為 "-" 或 "NaN"，轉換為空值，統計時標註為缺少同期數據。
3. **日期紀年標準化**：
   - 檢查「資料年月」欄位，將民國格式（如 `11509` 或 `115/09`）統一精準換算為 ISO 格式 `2026-09`。
4. **輸出品質報表**：
   - 列出資料清洗修復摘要（總行數、修復了幾筆字串、轉換了幾筆數值）。
   - 產出乾淨版的 CSV 內容供下載。
```

## 🔹 Prompt 1-2：探索性分析（EDA）與產業洞察（商管決策版）

```markdown
請根據剛才清洗完成的 1,088 家上市公司營收資料集，執行多維度探索性分析（EDA），為投資與產經會議產出決策報告：

### 分析面向：
1. **產業板塊總體量排行**：
   - 計算各「產業別」（如半導體業、電子零組件業、金融保險業、觀光餐旅業等）的「當月總營收（新台幣）」。
   - 計算各產業營收佔全市場總營收的百分比（%），並排行出前五大支柱產業。
2. **年增率（YoY）動能分析**：
   - 找出各產業平均年增率最高與最低的 3 個產業類別。
   - 標記出全市場營收成長率（YoY %）最高的前五大黑馬企業。
3. **客觀洞察與摘要**：
   - 提供 3 點高價值的產業集中度與景氣趨勢觀察（嚴格引用具體營收數字與百分比，不說空話）。
```

## 🔹 Prompt 1-3：算術交叉驗算（Cross-Verification）防幻覺專用

```markdown
【非常重要：防幻覺核對任務】
在提供上述統計結論時，請嚴格執行算術交叉勾稽（Cross-Verification），並在報告末尾以 Markdown 表格輸出你的驗算憑據：

### 驗算規範：
1. **加總勾稽（Row & Column Sums）**：
   - 將「所有個別上市公司的當月營收」加總，得到 $S_1$。
   - 將「各產業分類彙總營收」加總，得到 $S_2$。
   - 驗證 $S_1 - S_2$ 差額是否嚴格為 0。
2. **比率計算透明化**：
   - 凡涉及「佔比（%）」或「成長率」，必須列出：`【分子】 / 【分母】 = 【計算結果】`。
3. **勾稽狀態標示**：
   - 每個驗算項目後面請明確註明 `[PASS 驗算無誤]` 或 `[FLAG 存在誤差]`。

請確保不要單純依賴文字預測生成數字，請調用代碼執行器（Python / Code Interpreter）計算以保證 100% 準確！
```
