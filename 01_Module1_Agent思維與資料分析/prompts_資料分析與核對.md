## 🔹 Prompt 1-1：資料清洗與格式規範化

```markdown
你是一位具備 15 年經驗的資深商業與行政數據工程專家。我已經上傳了一份名為 `sample_dirty_data.csv` 的原始檔案。請你仔細檢查數據內容，並執行標準化的資料清洗流程：

### 執行規則：
1. **去除空白與字元規範**：去除所有欄位名稱與內文資料的前後空白字元（Trim Whitespace）。
2. **數值字串轉型**：
   - 將包含千分位逗號（例如 "150,000"）的字串轉換為純數值型態（Integer / Float）。
   - 檢查「實支金額」欄位，若遇到 "-"、"未結算" 或空白缺失值，請勿隨意填入 0，請將其設為空值（NaN / null），並在後續統計時特別註明為「未結案排除計算」。
3. **日期格式標準化**：
   - 統一轉換為標準 ISO 格式：`YYYY-MM-DD`。
   - 若遇到民國年（如 `115/04/08`），請精準換算為西元年（`2026-04-08`）。
4. **異常值檢查**：檢查預算金額與實支金額是否有負數、實支金額是否超過預算金額（超支情況），若有請在報告中標註。

### 輸出需求：
1. 直接提供清洗後的完整 CSV 內容（以代碼區塊呈現，方便下載）。
2. 列出清晰的「資料清洗問題與修復清單」（包含修復了哪些欄位與具體筆數）。
```

## 🔹 Prompt 1-2：探索性分析（EDA）與管理洞察

```markdown
請根據剛才清洗乾淨的資料集，進行深度探索性數據分析（EDA），為主管會議提供決策摘要：

### 分析面向：
1. **部門體量比較**：
   - 計算各業務部門的「總預算額度」、「已結案總實支金額」以及「整體預算執行率（實支 / 預算 %）」。
   - 排行出預算佔比最高的前三大部門。
2. **效益與滿意度評估**：
   - 計算全校活動的平均滿意度與中位數。
   - 計算「平均每人花費成本（實支金額 / 參與人數）」排名前三高與前三低的活動項目。
3. **洞察與具體管理建議**：
   - 提出 3 點客觀且具體的管理建議（例如：資源集中度問題、預算執行偏低之部門提醒、滿意度與預算關聯等）。請避免空泛口號，直接引用具體數據佐證。
```

## 🔹 Prompt 1-3：算術交叉驗算（Cross-Verification）防幻覺專用

```markdown
【非常重要：防幻覺核對任務】
在提供上述統計結論時，請嚴格執行算術交叉勾稽（Cross-Verification），並在報告末尾以 Markdown 表格輸出你的驗算憑據：

### 驗算規範：
1. **加總勾稽（Row & Column Sums）**：
   - 列出所有已結案項目的實支金額逐筆加總算式。
   - 驗證「各部門實支加總」是否與「全校總實支金額」完全一致（差額需為 0）。
2. **比率計算透明化**：
   - 凡涉及「百分比（%）」、「執行率」或「平均值」，必須同時列出：`【分子】 / 【分母】 = 【計算結果】`。
3. **勾稽狀態標示**：
   - 每個驗算項目後面請明確註明 `[PASS 驗算無誤]` 或 `[FLAG 存在誤差]`。

請確保不要單純依賴文字預測生成數字，請調用代碼執行器（Python / Code Interpreter）計算以保證 100% 準確！
```
