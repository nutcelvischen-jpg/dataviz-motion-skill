INTERACTIVE EXPLORER · 01

Token 是什麼？互動式分詞與成本試算沙盒

電腦只認得二進制數字，無法直接理解人類文字。LLM 透過 Byte-Pair Encoding (BPE) 演算法將文字切分成「詞元（Token）」。英文字詞通常 1 個單字切成 1~2 個 Token；繁體中文因多字元編碼，每個字約消耗 1.2~2.0 個 Token！

經典認知陷阱：為什麼早期 ChatGPT 數不出「strawberry」裡面有幾個「r」？

因為在 BPE Tokenizer 的詞彙庫中，「strawberry」直接被切割為兩個獨立 Token：straw (Token ID 11245) 與 berry (Token ID 32884)！模型從頭到尾根本「看不見」單獨的英文字母 r，它看到的是兩個語意向量。當你要求它數字母時，它只能憑統計機率猜測，因而頻繁出錯！這正是 Tokenize 機制帶來的結構性特徵。

CORE FOUNDATIONS · 02

大語言模型必懂 6 大專有名詞視覺圖解

在進入 Module 1 的資料分析與 Module 2 的自訂 Skill 之前，這些核心詞彙是工程師與 AI 溝通的共同語言：

01 / QUANTUM OF LLM
Token（詞元）與 Tokenize
LLM 處理資訊的最小單位。英文通常由詞根、詞綴組成（如 un-believable 切為 2 個），中文常見 1 字對應 1~2 個 Token。Token 數量直接決定 API 帳單與運算延遲。
1 Word ≈ 1.3 Tokens ｜ 1 中文字 ≈ 1.5 Tokens
02 / BILLING & AUTH
API Key（金鑰憑證）
你在雲端模型供應商（OpenAI、Anthropic、Google）處的數位身分證與信用卡扣款憑證。具備極高資安敏感性，一旦直接寫死在前端 HTML/JS，會被爬蟲一秒盜刷成千上萬美元！
Headers: {"Authorization": "Bearer sk-..."}
03 / MEMORY CAPACITY
Context Window（上下文視窗）
模型單次對話能夠同時「閱讀」與「輸出」的最大 Token 上限。從早期 GPT-3.5 的 4K，進化到 GPT-4o 的 128K，再到 Gemini 1.5/2.5 Pro 的 2,000,000 Tokens（可直接吃下幾十本書或幾小時影片）！
Window = Prompt Tokens + Output Tokens
04 / CREATIVITY TUNING
Temperature & Top-P（採樣溫度）
控制模型輸出時的隨機性。Temperature 越低（如 0.0），模型只挑選機率最高的字，回答嚴謹、確定、適合資料分析與算術；越高（如 0.8~1.0），模型會隨機選取邊緣詞彙，適合創意寫作。
P(w) = softmax(z_i / Temperature)
05 / GEOMETRIC SEMANTICS
Embeddings（向量嵌入空間）
將文字轉換成數千個維度的浮點數向量（如 1536 維）。在幾何空間中，「國王」與「女王」的向量方向平行於「男人」與「女人」。RAG（檢索增強生成）正是利用餘弦相似度在向量空間找相關文檔。
Similarity = cos(θ) = (A · B) / (||A|| ||B||)
06 / CONTROL LAYER
System Prompt（系統提示詞）
在對話最一開始由開發者注入的最高指導方針，規範模型的角色、語氣、輸出格式與邊界。但如同我們在北捷案例所見：System Prompt 不是物理防火牆，仍會被惡意 Prompt Injection 繞過！
role: "system", content: "You are an expert analyst..."
MODEL TAXONOMY · 03

全球主流大模型全景圖譜 (The Modern LLM Landscape)

當今世界的大模型已非單一巨頭獨大，而是形成了「美國雲端旗艦」、「亞洲高性價比開源突破」與「地端隱私引擎」三大陣營：

OPENAI · 美國 雲端多模態旗艦
GPT-4o & GPT-4o-mini

全球商業落地最廣泛的旗艦模型。原生全模態架構（文字、視覺、音訊同源處理），具備頂級指令遵循能力與極低延遲。

上下文視窗 128K Tokens
輸入價格 $2.50 / $0.15 (mini)
核心強項 通用智能 · 生態豐富
適合場景： 企業級穩定生產環境、複雜多步驟 Agent 推理、結構化 JSON Schema 強制輸出。
ANTHROPIC · 美國 編程與邏輯天花板
Claude 3.5 Sonnet

由前 OpenAI 核心成員創立，目前在軟體工程（SWE-bench）與複雜長文本代碼生成領域公認的第一把交椅。文筆自然典雅，AI 味最淡。

上下文視窗 200K Tokens
輸入價格 $3.00 / 1M
核心強項 寫 Code · 深度推理
適合場景： 專業代碼重構、大型專案架構審查、長篇學術研究論文閱讀與分析。
GOOGLE DEEPMIND · 美國 超長上下文之王
Gemini 1.5 / 2.5 Pro & Flash

以業界首創的「百萬級超長上下文」震撼業界。可一次性載入 1 小時影片、數百頁財報或整套程式庫；結合 Google 搜尋與工作區生態。

上下文視窗 1M ~ 2M Tokens
輸入價格 $1.25 / $0.075 (Flash)
核心強項 200萬超長窗 · 影音分析
適合場景： 全年財務年報交叉勾稽、多小時錄音與影片轉錄、巨型專案完整代碼庫靜態分析。
DEEPSEEK · 中國杭州 極致性價比 · 開源巨震
DeepSeek-V3 & DeepSeek-R1

2025 年引發全球 AI 界震撼的黑馬。採用創新的 Multi-head Latent Attention (MLA) 與 DeepSeekMoE 架構，以僅有美國巨頭十分之一的成本實現匹敵頂級閉源模型的能力！R1 更在數學推理上達標頂峰。

上下文視窗 64K ~ 128K Tokens
輸入價格 $0.14 / 1M (極便宜)
核心強項 數學推理 · 1/20 成本
適合場景： 高並發批次資料分析、算術與演算法競賽、預算敏感型專案的最佳首選。
ALIBABA CLOUD (阿里巴巴) · 中國 開源社群全尺寸霸主
Qwen 2.5 (通義千問)

全球開源社群下載量最高的開源家族之一，涵蓋從 0.5B、7B、14B 到 72B 全尺寸模型。在多語言支援、中文語境、數學與代碼能力均位列開源榜首。

上下文視窗 128K Tokens
開源授權 Apache 2.0 (多數開源)
核心強項 地端自建 · 跨尺寸部署
適合場景： 企業私有化地端部署、邊緣設備運行（7B）、金融與多語言本地化微調。
MOONSHOT AI (月之暗面) · 中國北京 中文長文本開拓者
Kimi (Moonshot v1)

以 20 萬字無損超長上下文一戰成名。專注於中文長篇閱讀、專業法律合同解讀、網頁即時搜尋與整理，深受華語圈知識工作者歡迎。

上下文視窗 200K Tokens
部署形態 雲端 API & Web/App
核心強項 中文文案 · 文檔摘要
適合場景： 幾十萬字投行研報梳理、中文合約風險審查、互聯網新聞熱點即時聯網搜集。
MINIMAX (名之夢) · 中國上海 多模態與海螺 AI
MiniMax-abab 6.5 & 海螺

擁有自主研發的 MoE 架構語言模型，並在「語音合成（TTS）」與「高擬真視頻生成（Video-01）」領域名列前茅。旗下海螺 AI 具備強大的長對話陪伴與創作能力。

上下文視窗 245K Tokens
多模態 文字 · 語音 · 視頻
核心強項 擬真人聲 · 角色扮演
適合場景： 互動式語音客服、數位人播報配音、多模態創意故事創作與娛樂社交應用。
OLLAMA · 開源工具 地端離線引擎霸主
Ollama (Local LLM Engine)

不是單一模型，而是「讓你在自己電腦一行指令跑大模型」的最佳工具！支援 Llama 3、Qwen 2.5、DeepSeek-R1-Distill、Gemma 等，提供本機 11434 端口與標準 OpenAI 相容 API。

運行環境 Mac (Apple Silicon) / Linux / Win
Token 費用 $0.00 (完全免費)
網路需求 100% 離線可用
適合場景： 機密財務資料不聯網分析、個人電腦離線助手、無網路環境或機密隔離區（Air-Gapped）。
ARCHITECTURE TRADEOFFS · 04

地端模型 (Local / Ollama) vs. 雲端模型 (Cloud API) 架構圖解

身為資料分析師或架構師，什麼時候該呼叫 OpenAI / Claude 雲端 API？什麼時候該在筆電或內網私有化部署 Ollama？關鍵在於權衡五大維度：

決策維度 ☁️ 雲端 API 模式 (OpenAI, Gemini, Claude) 🏠 地端自建模式 (Ollama, vLLM, 私有伺服器)
🔒 數據隱私與合規 資料需傳送至外部伺服器
雖然商業 API 承諾不使用客戶資料訓練，但在高度管制的金融、醫療、國防領域，外部傳輸本身即可能違反法規。 		100% 物理留存本地，零資料出境
網路線拔掉依然能流暢運行！完全符合最高等級 GDPR、醫療 HIPAA 或內部機密隔離規定。
💰 成本結構與收費 按量計費（Pay-as-you-go）
前期投入為 0；但如果業務流量極大（如每秒數百次呼叫），累積的 Token 帳單將非常可觀。 		前期硬體固定資產投入
日常呼叫 Token 邊際成本為 0！但需要投資高階 GPU（如 RTX 4090、A100 或 Mac M3/M4 Max 高統一記憶體）。
🧠 智能天花板與推理力 極致頂級（Frontier Intelligence）
背後是數千億甚至上兆參數的龐大叢集（如 GPT-4o, Claude 3.5 Sonnet），在複雜邏輯、跨領域推理遙遙領先。 		受限於本機顯存（VRAM）
個人筆電通常只能跑 7B~14B 模型，70B 需高階顯卡。在嚴密邏輯或細膩文筆上與雲端旗艦有明顯落差。
⚡ 部署與維運難度 零維運（Serverless）
申請 API Key，一行 requests.post 或官方 SDK 即可呼叫，全世界高可用性由巨頭維護。 		需要掌握基礎運維知識
需安裝 Ollama、配置 CUDA 驅動、處理量化格式（GGUF）、記憶體溢出（OOM）與高並發排隊問題。
