# 📊 Module 1：Agent 思維與資料敏捷分析講義

## 一、 單元學習目標
1. **打破聊天限制**：理解 Chatbot（單向回答）、Agent（自主推理與調用工具）、Skill（程序化專業技能）與 MCP（跨系統連線）之本質差異。
2. **掌握髒資料清洗**：學會下達精確 Prompt，讓 AI 一鍵修復缺失值、非純數字字串、混雜日期格式與異常離群值。
3. **建立防幻覺核對機制（Cross-Verification）**：掌握引導 AI 自動算術驗算（展示算式、總和檢核、前後指標勾稽）之關鍵心法。

## 二、 核心觀念解析：從「會問」到「會做」

### 1. AI 應用的四層演進階段
| 階段 | 名稱 | 互動特點 | 典型限制 |
| :--- | :--- | :--- | :--- |
| **Level 1** | **Chatbot (對話問答)** | 你問一句、它答一句 | 上下文易忘記、無法主動執行多步驟任務 |
| **Level 2** | **Skill (封裝技能)** | 注入標準 SOP、約束條件與特定格式 | 僅在特定平台內有效，無即時環境交互 |
| **Level 3** | **Agent (自主代理)** | 具備感知（Perceive）、規劃（Plan）、工具調用（Tool Use）與自我修正（Reflect） | 需要明確的邊界約束與目標導向 |
| **Level 4** | **MCP Agent (全通代理)** | 透過標準協定直連本地檔案、資料庫、API 與雲端服務 | 需注意權限管理與資安脫敏 |

### 2. 為什麼商業與行政資料分析必須「防幻覺」？
大型語言模型（LLM）擅長語言理解與邏輯推理，但在純文字生成模式下，對長數字加乘運算有潛在的「機率猜測（幻覺）」風險。
因此，在資料分析中必須掌握三大防幻覺法則：
1. **強迫調用運算核心**：要求 AI 撰寫並執行 Python (Pandas/Numpy) 程式碼，由編譯器完成數學運算，而非靠文字機率猜測。
2. **展示中間推導過程（Chain of Thought）**：要求列出分子、分母、樣本數與運算公式。
3. **收尾勾稽驗算（Reconciliation）**：要求 AI 將「各細項數值加總」與「資料表原始總額」進行等式比對，若不相等則強制警示。

## 三、 實作流程與步驟說明

### 步驟 1：取得練習資料集
本目錄已準備 `sample_dirty_data.csv`，其中刻意包含常見行政資料瑕疵：
- 欄位包含空白字元（如 `" 預算金額 "`）。
- 數值混雜千分位逗號（如 `"1,500,000"`，導致系統被識別為文字）。
- 缺失值（NaN、空白或標示為「-」）。
- 日期格式混雜（`2026/03/15`、`2026-03-16`、`115/03/17`）。

### 步驟 2：執行自動化資料清洗
使用 `prompts_資料分析與核對.md` 中的「Prompt 1-1：資料清洗指令」，上傳檔案並促使 AI 輸出標準化乾淨檔案。

### 步驟 3：產出探索性分析與防幻覺核對
使用「Prompt 1-2：算術防幻覺與摘要報告」，檢視 AI 是否主動展示交叉驗算通過證明。

### 步驟 4：對照標準報告成果
完成後，可打開 `分析報告範例_成果對照.md` 檢查自己的分析維度與結論是否完整。
