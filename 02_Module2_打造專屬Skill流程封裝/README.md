# ⚙️ Module 2：打造專屬 Skill 流程封裝講義

## 一、 單元學習目標
1. **理解 Skill 的本質**：區別「單次提示詞（One-off Prompt）」與「封裝技能（Reusable Skill）」的維度差異。
2. **掌握 SOP 結構化拆解**：將行政審核、學生輔導、會議紀錄等複雜工作流拆解為「角色、輸入條件、執行步驟、負向約束、輸出格式」。
3. **完成跨平台 Skill 佈署**：學會將 Skill 部署於 **Claude Projects**、**ChatGPT Custom GPTs** 與 **Antigravity Skills** 架構。

---

## 二、 為什麼我們需要「Skill 化」？

### 傳統 Prompting 的痛點：
- 每次開啟新對話都要重打一次背景與要求（「請扮演...不要用大陸用語...條列輸出...」）。
- 對話一旦變長，模型開始忘記初期規則（上下文稀釋）。
- 同事或助理無法輕鬆複用你精心調校好的提示詞邏輯。

### Skill 的工程化優勢：
- **固化專業知識（Knowledge Grounding）**：將學校法規、報銷標準、格式範本內建為知識庫。
- **高重複度與一致性**：無論何時呼叫，均能輸出結構穩定、格式標準的成果。
- **免除重複溝通成本**：一鍵呼叫，專注於輸入當下的業務資料。

## 三、 Skill 設計五大核心骨架（SOP 公式）

一套標準的生產級 Skill 必須具備以下五大要素：

1. **Role & Identity（專業角色與視角）**：賦予明確的年資、專業領域、心態與語氣。
2. **Context & Goals（任務背景與目標）**：定義本 Skill 解決的核心問題與邊界。
3. **Strict Constraints & Negative Prompts（正向規則與禁忌約束）**：
   - 必須做什麼（例如：以繁體中文回答、保留原本數字與日期）。
   - **絕對禁止做什麼**（例如：嚴禁空泛口號、嚴禁自行編造法規條號、不可刪減關鍵事實）。
4. **Step-by-Step Workflow（逐步推理流程）**：引導模型依序先思考、再檢視、最後撰寫。
5. **Output Schema（強制輸出規格）**：明確規範標題層級、段落標籤與格式（Markdown / 表格 / JSON）。

## 四、 本單元現成 Skill 範本庫 (`skills_library/`)
為便於學員課堂即學即用，本目錄提供 3 組專為大專院校行政與教學設計的現成 Skill：
- **`01_公文與行政企劃書智慧審核潤飾器/`**：解決公文贅字、主旨不明與法規用詞瑕疵。
- **`02_學生專案作業與商業報告回饋器/`**：針對學生期末報告產出具建設性、鼓勵性且標準化的評語反饋。
- **`03_會議紀錄與待辦任務萃取器/`**：將雜亂口語逐字稿自動萃取為「決議事項」與「追蹤清單（Action Items）」。
