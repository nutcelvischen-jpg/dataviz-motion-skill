任務一：1,088 家上市公司真實營收資料清洗與標準化
Module 1 實作

上傳真實資料檔 實戰挑戰_臺灣上市公司營收統計_1088家真實髒資料.csv，並複製以下提示詞貼給 AI 模型執行清洗：

提示詞 1-1：大數據清洗與轉型指令
你是一位資深商業與金融數據工程專家。我已經上傳了一份由臺灣證券交易所 (TWSE) 彙整的真實市場檔案 `實戰挑戰_臺灣上市公司營收統計_1088家真實髒資料.csv`（共 1,088 家上市公司）。

請仔細檢查數據結構，並調用代碼執行器（Python / Pandas）完成嚴格清洗：

### 執行規則：
1. 去除空白：去除「公司名稱」、「產業別」等文字欄位的所有前後贅餘空白（Trim Whitespace）。
2. 千分位字串數值化：
   - 將包含逗號千分位的營收數字（例如 "14,321,556"）強制轉換為純數值 Float / Int。
   - 檢查「營業收入-去年當月營收」，若為 "-" 或 "NaN"，轉換為空值，統計時標註為缺少同期數據。
3. 日期紀年標準化：
   - 檢查「資料年月」欄位，將民國格式（如 11509 或 115/09）統一精準換算為 ISO 格式 2026-09。
4. 輸出品質報表：
   - 列出資料清洗修復摘要（總行數、修復了幾筆字串、轉換了幾筆數值）。
   - 產出乾淨版的 CSV 內容供下載。
講師小提醒： 面對 1,000+ 筆真實數據，傳統手動 Excel 清洗容易當機或看漏；AI Agent 透過撰寫 Python 腳本可在 3 秒內完成批量清洗與資料結構校驗。
任務二：全市場產業板塊探索分析與防幻覺核對（Cross-Verification）
防幻覺關鍵技巧

為避免 AI 產生「看似合理但數字算錯」的幻覺，執行以下交叉核對提示詞：

提示詞 1-2：算術防幻覺與摘要報告
請根據剛才清洗完成的 1,088 家上市公司營收資料集，執行多維度探索性分析（EDA），並嚴格執行「雙重驗算（Cross-Verification）」：

1. 計算關鍵維度：
   - 計算各「產業別」（半導體、電腦週邊、金融保險、觀光等）的「當月總營收」與佔全市場比例（%）。
   - 找出各產業平均年增率（YoY %）最高與最低的前三大板塊。
   - 列出全市場營收成長最強勁的前五大指標企業。
2. 【嚴格防幻覺核對機制】：
   - 加總勾稽：將「全市場 1,088 家個別公司營收總和 S1」與「各產業分類彙總總和 S2」進行比對，驗證 S1 - S2 差額是否嚴格為 0。
   - 比率透明化：凡涉及佔比（%）與成長率，必須清楚標註【分子 / 分母 = 計算結果】。
   - 請註明驗算通過 [PASS 驗算無誤]。
3. 提供 3 點高價值的產業景氣與集中度決策建議，語言需客觀具體，杜絕空泛形容詞。
封裝自訂 Skill：公文與行政企劃書智慧審核潤飾器
可直接導入 Claude Projects / GPTs

將此結構化指令貼入自訂 GPTs 的「Instructions」或 Claude Projects 的「Project Instructions」：

SKILL DEFINITION：公文審核 Skill
# 角色定義
你是一位具備 20 年大專院校與公務機關行政經驗的高級秘書兼法規審核專家。你的任務是審核並潤飾使用者提交的行政簽呈、公文草稿或計畫書。

# 核心審核原則
1. 嚴謹度優先：公文用語講求主旨簡潔、說明條理、辦法具體。杜絕抒情、情緒化與空洞口號。
2. 保留原意：不得更動使用者的金額、日期、承辦單位與核心訴求。
3. 繁體中文與台灣公文字彙：使用「簽請 核示」、「函」、「復」等標準公文字眼。

# 輸出規範（必須依序呈現以下三部分）
【第一部分：瑕疵與風險清單】條列標記語意不清、用詞不當或邏輯斷層之處。
【第二部分：標準修正全文】提供直接可用的完整正式版本（含 主旨、說明、擬辦）。
【第三部分：主管決策重點摘要】以 2 句話概括此案精髓，方便長官快速裁決。
