# 📋 課前準備與環境檢核清單

歡迎參加**「一天打造你的 AI 工作流程：從 Agent、Skill、MCP 到數據影片」**進階實戰工作坊！
本工作坊實作比例超過六成，為確保當天課程節奏流暢，請於**開課前 1~2 天**依循本檢核清單確認筆記型電腦與帳號環境。

---

## 一、 硬體與網路設備
- [ ] **筆記型電腦**：攜帶個人筆電（Windows / macOS 皆可）與充電電源線。
- [ ] **瀏覽器**：請安裝最新版本的 **Google Chrome** 或 **Microsoft Edge**。
- [ ] **Wi-Fi 連線**：確認筆電可連線至校園無線網路（eduroam 或校內訪客 Wi-Fi），建議備妥個人手機熱點作為備用網路。
- [ ] **滑鼠（強烈建議）**：涉及網頁互動與圖表操作，使用實體滑鼠效率更佳。

---

## 二、 AI 帳號準備（請至少備妥其中一項付費版本）
課程將實作進階 Agent、檔案上傳分析與自訂 Skill 封裝，需使用具備進階模型與代碼分析能力的平台：
- [ ] **選項 A（推薦）**：**ChatGPT Plus**（支援 GPT-4o / Canvas / Advanced Data Analysis / Custom GPTs）
- [ ] **選項 B（推薦）**：**Claude Pro**（支援 Claude 3.5 Sonnet / Artifacts / Projects 知識庫）
- [ ] **選項 C**：**Google Antigravity / Gemini Advanced**（支援現代 Agentic Coding 與多模態工作流）

> 💡 **小叮嚀**：若您已有其中一項付費帳號即可，無需三種全部購買。當天實作會提供跨平台的提示詞與實作方案。

---

## 三、 本地開發與工具環境（選配，不影響無編程背景學員）
本工作坊以**「無編程背景亦可輕鬆上手」**為核心設計，大部分操作均可在瀏覽器與線上工作台完成。
若您對現代 Agentic Coding 感興趣，建議可先安裝：
- [ ] **Node.js（LTS 版本）**：[https://nodejs.org/](https://nodejs.org/)（用於本地渲染與腳本測試）
- [ ] **Git**：[https://git-scm.com/](https://git-scm.com/)（用於下載與同步課程教材倉庫）
- [ ] **VS Code** 或 **Google Antigravity IDE**：用於檢視程式碼與配置檔。

---

## 四、 教室投影防呆配套說明
- 由於一般教室投影幕畫面可能較不清晰，本次課程特別採用**「雙軌同步教學」**：
  1. 講師將操作步驟投影於大螢幕。
  2. 每一位學員可直接在個人筆電開啟教材中的 `WORKSHOP_BOARD.html`（即時看板）。
  3. 看板上同步提供所有單元的**提示詞（Prompt）**、**範例程式碼**與**資料集下載連結**，點擊按鈕即可**「一鍵複製」**，無需仰頭瞇眼抄寫投影幕！
