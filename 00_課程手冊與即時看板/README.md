# 📘 課程手冊：一天打造你的 AI 工作流程
### 從 Agent、Skill、MCP 到數據影片（Claude × ChatGPT × Antigravity 進階實戰工作坊）

- **主辦單位**：教育部「AI 驅動金融商管科技與技職人才培育計畫」
- **授課教師**：國立臺中科技大學 國際貿易與經營系 陳俊智 副教授
- **研習對象**：大專院校教師、行政同仁、研究助理與研究生
- **課程時長**：單日 6 小時（09:00 - 16:00，實作比例 > 60%）

---

## 🎯 課程核心目標
跳脫「一句一句單向問 AI」的初階聊天模式，全面邁向「依照個人業務 SOP 驅動 AI 代理人」的高階生產力模式。
學員將在一天內建立一套**完整的個人工作流閉環**：
1. **感知與獲取**：理解 Agent、Skill 與 MCP 邊界，學會結構化擷取與整理資料。
2. **分析與核對**：利用 AI 進行多維度數據洞察，並建立交叉檢驗機制防範 AI 幻覺。
3. **流程封裝**：將日常重複性的教學、行政或研究任務，固化成可重用的「自定義 Skill」。
4. **工具串接與建站**：運用 Antigravity 與 MCP 協定，打通本地資料與外部 API，無代碼搭建互動式儀表板。
5. **多模態成果呈現**：利用數據視覺美學與自動化管線，將冷冰冰的數據轉化為 60 秒動態解說短片。
