# 🎬 Module 4：60 秒動態數據短片製作講義

## 一、 單元學習目標
1. **掌握數據短影音敘事法則**：學會將複雜的多維數據轉化為「黃金 60 秒五段式敘事結構」（Hook 破題 $\rightarrow$ 時序反差 $\rightarrow$ 關鍵歸因 $\rightarrow$ 結構鎖定 $\rightarrow$ 行動收尾）。
2. **理解 Data Atoms 視覺力學美學**：
   - **連續動量（Continuous Momentum）**：相鄰圖表間不使用粗糙的全屏淡出，而是透過幾何節點的物理形變（如柱頭鎖定為折線錨點、折線爆發為散點粒子雲）實現無縫轉折。
   - **阻尼回彈（Damped Oscillator）**：數值成長與定位使用物理彈簧運動方程，帶來細膩自然的回彈質感。
3. **體驗高階聲音架構與智慧混音**：
   - 整合 **Earshot 程序化音效庫**（UI Click、Thock、Sub Hit）。
   - 語音旁白（TTS）播報時，BGM 自動平滑衰減 -10dB（**Auto-Ducking 智慧音量避讓**）。
4. **全代碼自動化出片**：無須繁瑣手動剪輯，透過 Node.js + Headless Chrome + FFmpeg 一鍵渲染出 1080p 60FPS 商業級 MP4 影片。

## 二、 60 秒數據短片黃金五段式結構

| 秒數 | 敘事階段 | 視覺畫面特徵 | 聲音與音效設計 | 旁白節奏重點 |
| :--- | :--- | :--- | :--- | :--- |
| **00 - 10s** | **Hook 爆點破題** | 原始雜亂數據瞬間凝聚為立體柱狀體量排行，高亮第一名 | 沉穩 Sub Hit 重擊 + UI Click | 一句話直指痛點或反常識現象 |
| **10 - 25s** | **時序反差與拐點** | 柱狀頂端化為貝茲曲線展開，MA7 均線平滑流淌，標註拐點 | 晶片通電微高音 + 節奏鼓點 | 揭示趨勢變化，打破原有假設 |
| **25 - 40s** | **深度歸因與相關性** | 均線爆發為散點粒子雲，回歸線劃過，顯示 Pearson $r$ 與晶片 | 俐落 Thock 音效連續打點 | 拿出科學數據，證明因果相關性 |
| **40 - 55s** | **二八法則與結構** | 散點收束為環形佔比圖，80/20 帕累托動態高亮鎖定 | 舒緩旋律 + 輕量 Plink 音效 | 點出核心貢獻者，提出減法決策 |
| **55 - 60s** | **行動收尾與品牌** | 六大原子動態旋轉聚合，定格為決策閉環矩陣與品牌標語 | 收尾 Downlifter 下沉音效 + 全場混響 | 強調行動呼籲（Call to Action） |
