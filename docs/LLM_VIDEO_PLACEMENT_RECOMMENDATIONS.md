## 課程順序

新手的概念學習依序為 EP0 模型基礎 → EP1 Prompt → EP2 Context Engineering → 數位乩童 Agent 總覽。這是影片順序，網站原六站與完成進度維持既有設計。《AI 漏斗》可作為課前動機影片，或學完後再討論；不用設為必看門檻。

五片合計約 11 分 11 秒。各頁只放該頁最相關的一支播放器，其餘透過延伸入口到同一份影片，避免整頁同時出現五個播放器。

## 每片搭配一個觀看問題

- EP0：為什麼「講得順」不等於「講得對」？
- EP1：把「幫我寫報告」補上任務、資料與輸出要求，會有什麼差別？
- EP2：這一題需要哪些資料？有哪些資料可以先不放進 Context？
- 數位乩童：哪一步由模型提出請求，哪一步由程式或工具真正執行？
- AI 漏斗：你目前如何使用 AI？可以選哪個能核對結果的小任務開始？

## 呈現方式

保留原片名，旁邊附正式概念副標題，例如「布壇｜Context Engineering：準備這次要用的資訊」。影片使用直式封面、片長、兩行摘要、使用者點擊播放與原生控制項，不自動播放。桌面播放器寬度約 320–400px，手機依容器寬度顯示；影片下接目前的圖解、名詞連結及操作。

影片中的宗教意象作為比喻，正式名詞與機制仍以網頁說明對照。若引用漏斗人數、比例與人物引言，旁邊標記原始來源、日期與估計性質；EP0 的容量或機率示意也不作為所有模型的固定規格。
