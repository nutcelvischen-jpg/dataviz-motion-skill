# 簡化導覽與閱讀流程：修改及驗收紀錄

日期：2026-11-01。依使用者確認的簡化方向實作；先以記憶課整併閱讀與操作，再套用其餘五站及查閱、實驗流程。

## 本機入口

- 首頁／跟著學：http://127.0.0.1:8765/index.html
- 查概念：http://127.0.0.1:8765/encyclopedia.html
- 記憶課：http://127.0.0.1:8765/learn.html?lesson=02
- 做實驗：http://127.0.0.1:8765/lab.html

以 `python3 scripts/llm_preview.py` 啟動。保持原來的 `127.0.0.1:8765` 與同一瀏覽器即可使用原進度及設定。另使用 8767 作為驗收網址，沒有重設使用者的正式進度。

## 修改結果

| 原本的使用負擔 | 本次處理 |
|---|---|
| 主導覽同時列出課程、圖鑑、圖解、案例等不同層次 | 統一為「跟著學、查概念、做實驗」三項；圖解和案例放在相關主題下一步 |
| 圖鑑頁同時有章節側欄、頂部目錄、名詞區及大量正文 | `encyclopedia.html` 成為搜尋／分類目錄；完整內容拆到 `concepts/` 的 21 個主題頁 |
| 查一個名詞，仍要在長頁中找對應段落 | 中英文、全形英文及常用簡繁別名搜尋；整列進入該主題，返回時還原查詢及分類 |
| 六站同一頁上有許多同等重要的段落 | 依「動手試 → 看解說 → 確認理解」閱讀；較長內容與延伸資料用可展開區塊保留 |
| 實驗室預設直接進入一個實驗，其他項目不易掌握 | 不帶參數的 `lab.html` 先顯示三組八個實驗；實驗內集中操作與結果 |
| 自由測試入口容易忽略 | 目錄有「連接自己的模型與 API Key」，各實驗頁有「API Key／自由測試」入口；課程延伸可直接展開 |

五類名詞用於查閱：模型與資料、提示詞與上下文、Agent 與工具、安全與查證、圖形與介面。六站用於學習順序與進度，兩者用途分開。

- 八個實驗 ID、27 組原預設、原有系統指引、解析、結語與來源保留。Token 工具、用量計算、模型篩選、API 試演在各自頁面初始化。
- `js/learning-progress.js`、`js/lab-legacy-data.js`、`js/model-reference-data.js` 與本輪修改前快照逐位元相同。既有進度及金鑰儲存名稱未變。
- 原版 `dist_public_web/` 未修改。本輪修改前快照：`backups/llm-before-simple-navigation/`。
- 沒有部署、推送、付費模型呼叫或讀取真實金鑰。原教材既有的待核對提示保留；本輪不是模型規格與來源的全面事實查核。
