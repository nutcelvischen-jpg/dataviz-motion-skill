# 教材內容待核對清單

本次屬內容結構與介面重整，沒有逐項查證舊研究、模型資料或新聞案例；以下列出影響閱讀與使用的事項，供後續查核。

| 項目 | 發現與處理 |
|---|---|
| 模型與產品資料 | 舊模型名稱、功能、部署條件及排名沒有逐項對照原廠。比較表標示「既有教材，待核對」，完整原文留在個別細節。 |
| 價格資料不一致 | 原教材的不同價格表有不一致的模型費率，例如 Claude Opus 5.5 在不同位置出現不同輸入數字。本次未猜測哪一筆正確；舊表標示待核對，主要練習使用明確教學假設。 |
| 模型來源與日期 | 原文含「官方」「最新」「即時」等字樣，但本次沒有確認各筆來源與資料日期。新主介面不把本次編輯日期當成資料核對日期。 |
| Strawberry 與分詞 | 簡化分詞非正式 BPE；主文避免宣稱所有模型必然數錯，舊長篇標示為待核對教材。 |
| 記憶與成本 | 主文區分應用保存、當次輸入和模型回覆；累積成本示例明列等長與完整重送假設。 |
| 北捷案例 | 主案例為教學改寫及固定示範；新聞連結與其他具體話術、回覆的對應關係未逐一核對。舊手機教材獨有敘述以待核對原文保留。 |
| 代理人事件、蒸餾與產業數據 | 長篇原文已搬到專題，並在頁首和相關段落標示待核對；情境推演與政策觀點分開。 |
| 前沿研究 | 原教材中模型性能、研究事件與太空算力相關敘述尚未全面確認，保留於選讀並標示資料狀態。 |
| API 安全與預算 | 教學圖說明後端管理、權限與用量；不把單一技術或某個預算設定描述為全面保證。 |

若日後對資料進行核對，應記錄具體來源、資料日期、核對日期與適用版本；不能直接將本次編輯日期作為查核日期。
