## 實際限制

- 真實付費 API 沒有發送請求，無法保證個別供應商的帳號權限、網路限制與即時回應；教學核心不依賴真實 API。Gemini 原有 2.0 Flash 已停用，2026-11 改為官方建議替代的 3.6 Flash（https://ai.google.dev/gemini-api/docs/deprecations）。
- 舊模型、價格與研究資料沒有全面事實查核，詳見 LLM_CONTENT_REVIEW_NOTES.md。
- 未以實體螢幕閱讀器測試；已檢查部分鍵盤操作與語意。
- 瀏覽器自動化的放大快捷鍵未改變縮放比例，未完成實際 200% 瀏覽器縮放測試；已獨立檢查多個窄螢幕尺寸。
- 自動化瀏覽器不允許讀取 file: 網址，測試使用本機 HTTP 預覽。不同網址或埠號的瀏覽器進度互相獨立。
