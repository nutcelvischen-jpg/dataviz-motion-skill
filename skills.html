Skill 與 MCP 清單

工作坊用到的 27 個 Antigravity Skill（4 個領域）與 3 個 MCP 伺服器，每一項都附原始倉庫連結。

前端品味與介面工藝動態視覺與知識短影音數據視覺化與架構圖解代理人工程、行為守則與導師MCP 工具

在 Antigravity 代理人環境中，我們不再是從零手寫樣板程式碼，而是調用專業封裝的 Skill。以下是本專案在「前端品味工藝、動態短影音、數據視覺化與代理人工程」4 大核心實戰領域所嚴選整合的 27 款開源 Skill 清單，皆附上 GitHub 原生倉庫連結供學員收藏、進階探索與自訂技能擴充：

MCP 工具3 個伺服器

Model Context Protocol (MCP) 是連接 AI 代理人與外部世界（跨國開放資料、3D 建模軟體、即時新聞源）的標準協議。以下精選 3 款在資料分析、3D 渲染與新聞事實查核極度好用的實戰 MCP 服務與開源端點，可直接配接至 Claude Desktop、Cursor、Codex 與 Antigravity 代理人：

  • 跨國政府開放資料 / 單一 MCP 端點

    Twinkle Hub MCP

    將 7 個國家與地區（台灣、香港、日本、韓國、美國、新加坡、英國）的政府開放資料統一封裝為 MCP 服務。單一 API Key、收錄超過 769,422+ 筆資料集，代理人可隨時秒級調取全球官方數據進行分析。

    端點類型：全託管雲端 MCP 伺服器 (https://api.twinkleai.tw/mcp/)

    官方網站
  • 3D 軟體控制 / Blender 自動化

    mcp-for-blender

    讓任何 LLM 代理人直接控制 Blender 3D 的開源社群外掛。代理人可藉由自然語言直接生成幾何模型、調節材質著色器、設定攝影機燈光軌跡，並全自動調用 Cycles/EEVEE 渲染引擎輸出算圖。

    端點類型：本地 Blender Python MCP Socket 外掛

    GitHub
  • 國家通訊社 / 即時事實查核與新聞源

    中央社 AskCNA MCP

    台灣中央通訊社官方 AI 新聞與查核服務。提供 CNA MCP Server 把最可信的國家級新聞源接進 AI 工具，支援跨語言即時時事問答、歷史報導大數據檢索與深度事實比對。

    端點類型：官方授權新聞數據檢索 MCP 服務

    官方服務

支援 Client：Antigravity IDE · Claude Desktop · Cursor · Codex · Windsurf
