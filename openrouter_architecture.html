OpenRouter 三階資料流

任何向大模型發起的 API 請求，都依賴其「上下文與外部工具邊界」。本圖解以動態封包粒子（Data Packets），帶您具象化看懂大語言模型從「缸中之腦（Zero Context）」、「檢索增強（Web Grounding / RAG）」到「代理人工具循環（Tool Calling / Agent Loop）」的完整資料流向。

三階資料流架構深度解構與工程指標對比

在生產環境中，選擇哪一種 API 調用方式取決於「精準度要求、Token 預算與外部安全性防護邊界」。

階梯 1 · ZERO CONTEXT

1. 裸模型直接對話 (Raw LLM)

最簡單的原型調用。使用者輸入什麼，就原封不動直接打進模型。模型是完全切斷外部感知、被「冷凍在訓練完成那天」的機率矩陣（缸中之腦）。

  • 傳輸跳數： 1 來回（Client ⇄ OpenRouter ⇄ LLM）
  • 延遲耗時： 極低 (~300 - 600 ms)
  • Token 消耗： 僅使用者輸入字數，成本極低
  • 時間/事實盲區： 100% 盲區，無法回答現在幾點或即時資訊
  • 運算能力： 僅能作文字機率預測，心算大數字極易出錯
Python API 呼叫範例 JSON
requests.post( "https://openrouter.ai/api/v1/chat/completions", headers={"Authorization": "Bearer sk-or-v1-..."}, json={ "model": "openai/gpt-3.5-turbo-16k", "messages": [ {"role": "user", "content": "現在台北幾點？"} ] } )
階梯 2 · WEB GROUNDING / RAG

2. 聯網 / 外部檢索增強 (RAG)

透過編排層攔截問題，先執行 Web 搜尋或向量檢索，將帶有「時間標記與可靠依據」的外部文本拼接進 System/Context，再送入 OpenRouter。

  • 傳輸跳數： 2 來回（先問外部資料源 ➔ 再送入大模型）
  • 延遲耗時： 中等 (~1.2 - 2.5 秒)
  • Token 消耗： 增強上下文需額外消耗 500 - 2000 Tokens
  • 時間/事實盲區： 完全消除，依賴搜尋回傳的時間戳作答
  • 防禦關鍵： 外部檢索內容可能夾帶間接提示詞注入（Indirect Injection）
Python 檢索注入範例 JSON
# 取得外部即時天氣資料 evidence = weather_api.get_current("Taipei") requests.post( "https://openrouter.ai/api/v1/chat/completions", json={ "model": "anthropic/claude-haiku-4.5", "messages": [ {"role": "system", "content": f"依據即時證據作答：{evidence}"}, {"role": "user", "content": "現在台北下雨了嗎？"} ] } )
階梯 3 · TOOL CALLING AGENT

3. 工具調用與雙向驗算 (Agent Loop)

將模型視為「調度決策大腦」而非計算機。模型遇到計算或專案任務時輸出結構化指令，由本機安全環境執行後二度送回，達到 100% 嚴謹驗算。

  • 傳輸跳數： 2 次 API 握手 ＋ 1 次本機代碼執行循環
  • 延遲耗時： 較高 (~2.5 - 5.0 秒，取決於工具運算)
  • Token 消耗： 包含 Tools Schema 與工具回傳二次推理
  • 時間/事實盲區： 完全消除，可直接掛載本機時鐘感測器
  • 運算能力： 100% 絕對精確（交由 Python/SQL 執行運算）
OpenRouter Tool Calls 雙向範例 JSON
# Step 1: 帶入工具定義 res1 = requests.post(url, json={ "model": "google/gemini-2.5-flash", "tools": [{"type": "function", "function": {"name": "calc"}}], "messages": [{"role": "user", "content": "120+80+50"}] }) # Step 2: 本機執行後送回 call = res1.json()["choices"][0]["message"]["tool_calls"][0] result = eval(call["function"]["arguments"]["expr"]) # 250 res2 = requests.post(url, json={ "messages": [..., {"role": "tool", "content": str(result)}] })
