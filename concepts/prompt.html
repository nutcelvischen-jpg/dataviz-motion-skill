Prompt：把任務交代清楚

Prompt（提示詞）是提供給模型的指示或問題。好的指示讓模型知道要完成什麼，以及如何判斷結果是否符合需求。

較籠統的說法

「幫我整理報名資料，做一張圖。」

資料範圍、統計方式和預期結果都還不清楚。

說清楚任務與條件

「整理這份活動報名表，計算各組報名人數，檢查缺漏與重複，再畫長條圖。列出統計方式，不要對外分享資料。」

可以依任務補上目標、資料、步驟、輸出格式與限制。應用程式也可能提供 System Prompt（系統提示詞），用來設定整體行為；實際指令優先順序依平台與系統設計而異。

不同來源的訊息

System Prompt 可提供應用程式的整體規則；User Prompt 表達使用者這次的需求。工具回傳與外部文件則可能是待處理資料，不應自動視為新指令。不同服務對角色與優先順序的定義可能不同。
