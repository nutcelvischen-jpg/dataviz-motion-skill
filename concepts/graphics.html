Graphic 與 Generative UI：讓結果看得懂、用得上

模型或 Agent 的結果不只有文字，也可能由應用程式與工具呈現為圖表、圖解或可操作的介面；實際能力取決於使用的系統與工具。

Graphic：圖形與圖表

用圖表、圖像或圖解表達資訊，例如把各組報名人數畫成長條圖。看圖時仍要核對資料、尺度與標籤。

Generative UI：生成式介面

應用程式可依任務或模型結果組出介面，例如同時提供圖表、篩選條件與資料表，讓使用者繼續查看。

  1. 準備資料確認欄位與來源
  2. 選擇工具計算與產生視覺結果
  3. 核對結果檢查筆數、圖形與標示
  4. 呈現與操作依需要提供圖表或互動

Graphic 是呈現形式，Generative UI 是組織互動畫面的方法；兩者都不是 Agent Loop 必然具備的功能。

參考：AI SDK：Generative UI 概念。

Computer Use：看畫面與操作

有些系統提供電腦操作工具，讓代理人觀察螢幕畫面並提出滑鼠或鍵盤操作。這是與環境互動的能力；它不同於產生圖表，也不同於生成介面。操作結果仍須檢查，權限與需要人工確認的動作應由應用程式管理。

參考：Anthropic：Computer Use。
