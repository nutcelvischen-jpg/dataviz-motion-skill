API、金鑰與後端代理

API 是應用程式呼叫服務的介面；API Key 是服務用來識別與授權請求的憑證之一，可能關聯額度與費用。BFF（Backend for Frontend）可讓瀏覽器向應用後端提出請求，再由後端管理憑證及呼叫模型。

本網站的真實 API 試演由瀏覽器直接連接供應商；選擇儲存或送出時，金鑰會保存在目前瀏覽器的本機儲存空間。這是個人教學測試，正式多人使用的應用仍需受控後端、身分驗證、權限與用量管理。
