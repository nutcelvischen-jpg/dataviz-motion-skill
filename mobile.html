01. LLM (大語言模型本質)
機率接話機
「純統計接龍，不是有意識的水晶球」

LLM 本質是一組被凍結的高維浮點數權重矩陣。它不具備大腦思考，而是計算哪個字在統計學上「最可能接在後面」：

4 步自回歸生成循環
1
提示詞輸入 (Prompt)：接收使用者句子
⬇️
2
凍結權重矩陣：兆級數值特徵運算
⬇️
3
Softmax 機率骰子：計算全字典候選字分數
⬇️
4
吐出最高分詞：接續並重複下一輪循環
💡 實例： 輸入「床前明月」 ➔ 候選字：光 (98.2%)、地 (0.8%)、餅 (0.001% 幻覺)。
02. Token（詞元切片）
基本粒子
「語言的切片樂高積木，計費的量子單位」

電腦不認得文字，只能算整數！Tokenizer 分詞器像一台字典切片機，把文字切成積木碎片並標記編號：

BPE 切詞流程圖
1
自然語言長句：「我正在使用 AI」
⬇️
2
BPE 切詞機：拆為 ["我", "正在", "使用", " AI"]
⬇️
3
數字 Token ID：查表對應 [2814, 18920, 521, 991]
⚠️ 避坑真相： 英文 1 單字 ≈ 1.3 Token，繁體中文因多字節編碼 1 字 ≈ 1.5~2.0 Token（中文天然貴 40%）！
03. API Key（金鑰憑證）
電子信用卡
「VIP 門票與自動扣款信用卡」

每次發出請求，雲端閘道依據你的 Key 即時核對帳戶餘額、並依 Token 數量扣款放行：

金鑰授權放行流程圖
1
你的手機應用 (Client)
⬇️
2
帶上私密金鑰 Header：Bearer sk-proj-...
⬇️
3
API 閘道查核扣款：驗證額度合法性
⬇️
4
放行調用萬張 GPU：開始極速運算生成
🚨 致命紅線： 絕不可寫在前端 HTML/JS！爬蟲 3 秒掃描抓走，跨夜直接盜刷上萬美元！
04. Context Window（上下文視窗）
書桌容量極限
「書桌物理面積極限，超限就掉入垃圾桶」

模型單次運算能攤在桌面上「同時看見」的最大資料量。包含系統提示、對話小抄與本次回覆：

容量與遺忘截斷機制
1

⬇️
2

⬇️
3
撞擊邊界溢出 💥：最舊紀錄被推落垃圾桶 🗑️ (遺忘)
💡 桌面進化： GPT-3.5 (4K 小茶几) ➔ GPT-4o (128K 會議桌) ➔ Gemini 4 (1M~2M 整座圖書館)。
05. Temperature（採樣溫度）
機率隨機旋鈕
「理性與狂熱的調控閥」
三態溫度滑塊對照
🧊 T = 0.0 (絕對理性/冰點)
永遠選 Top-1，100% 確定、毫無隨機性。
適合：SQL 查詢、數據分析、財報驗算
☕ T = 0.7 (室溫黃金平衡)
80% 主力 + 20% 輕微發散，生動流暢。
適合：通用對話、公關新聞稿、翻譯
🔥 T = 1.2+ (狂熱沸騰)
機率拉平，邊緣冷詞爆發，極易胡言亂語。
適合：科幻小說腦力激盪、荒謬創意

語意 GPS 座標
「讓電腦用幾何距離理解意義」

把文字投射到上千維度的超空間中。意思越近，空間距離越短：

語意空間測量流程圖

為什麼問傳統 AI：「strawberry 有幾個 r？」它常答「2 個」？

人類肉眼 vs LLM 切片對照
👁️ 人類掃描：s-t-[r]-a-w-b-e-[r]-[r]-y ➔ 精確數出 3 個。
🤖 LLM 分詞：[straw] (#11245) + [berry] (#32884) ➔ 字母實體消失，berry 誘發 double-r 機率記憶，脫口猜「2 個」！
