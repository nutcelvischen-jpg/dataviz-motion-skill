申請步驟速查

  1. 1登入並進入個人頁

    前往 e-Stat 官網右上角點擊「My page」進入會員控制台。若原為日文版可切換為英文版。

  2. 2鎖定 API 機能選單

    點擊深藍色功能橫條中的 ▶ API function (application ID issuance) 進入金鑰管理表。

  3. 3URL 嚴格規範

    官方防禦機制嚴格禁止純 localhost！請務必填寫 http://test.localhost 即可直接通過驗證。

  4. 4點擊 Issue 發行

    點擊右側 Issue 按鈕，系統立即生成 40 碼專屬金鑰（appId），後續呼叫 REST API 即可代入。

最常見的錯誤：URL 欄不能填 http://localhost，請填 http://test.localhost。
