ATTACK MODALITIES · 攻擊形態

一、 模型蒸餾攻擊之技術原理、運作形態與工業級基礎設施

傳統知識蒸餾原為內部輕量化部署技術；然而當前沿模型透過雲端 API 提供服務時，未經授權的大量查詢可能構成「模型擷取攻擊（Model Extraction Attacks）」；授權蒸餾與未授權擷取並非同一件事。攻擊者在黑盒或灰盒條件下，將目標 API 視為無標籤資料標註工廠，逆向探測內部決策邊界，大量生成高密度微調語料，藉對手前沿模型研發成果實現低成本跨代追趕。

🎯 三大蒸餾攻擊類型與掠奪目標
蒸餾類型 運作機制 擷取核心目標 典型用途與效益評估
功能複寫 (Functionality Replication) 廣泛輸入通用或領域查詢，截取模型最終文本標籤 對話風格、格式規範、指令遵循能力 複製模型常規對話與基礎功能，節省逾 70% 預訓練與標註成本
思維軌跡擷取 (Reasoning Trace Extraction) 設計特定提示誘發模型逐步思維鏈，擷取解題脈絡 邏輯演繹步驟、代碼架構分析、工具呼叫規劃 用於監督微調與強化學習，教導學生模型思考邏輯而非單純模仿答案
強化學習獎勵標註 (Reward Model Synthesis) 利用模型對候選回應進行多維度評分與反饋篩選 評分準則、偏好排序信號、品質打分 取代人類回饋強化學習的高昂人工標註成本，低成本訓練自研獎勵模型
🌐 「九頭蛇叢集」（Hydra Cluster）住宅代理池
攻擊實體批量註冊成千上萬個虛假學術機構、新創公司帳戶，配合虛擬信用卡與外洩憑證，經由遍布全球的住宅代理節點分發高頻查詢請求。即便單一帳號被封禁，備援帳號數秒內無縫遞補，將惡意流量稀釋混入正常用戶請求中，使傳統單一 IP/Key 速率限制徹底失效。
🔀 靜默流量重導向（Silent Redirection）與誘騙
部分下游中繼平台在未告知使用者下，暗中將真實用戶提示詞轉發至 Claude 等前沿模型 API，將生成結果回傳用戶的同時，在後端完整留存提示與回應作為自研微調語料。同時藉由精密對抗性系統提示詞與結構化標籤，強迫模型吐出未經精簡的完整推論記憶區塊。

DEFENSE ARCHITECTURE · 三大防禦體系

三、 三大核心防禦技術體系與博弈機制

🛡️ 防禦一：語境綁定與「保留思維」（Preserved Thinking）
密碼學簽名前綴綁定
傳統 API 會將推理過程作為可見明文回傳，極易被蒸餾截取。Anthropic 導入「保留思維」機制：在模型思維鏈輸出區塊注入具備密碼學簽名的特殊前綴（Cryptographic Prefix Binding）。客戶端在進行多輪對話時，必須原封不動回傳該加密簽名區塊以證明上下文合法性；任何企圖以自訂標籤篡改、截斷或替換思維軌跡的請求將直接引發簽名校驗失敗而被中斷，從根本上切斷了自動化思維軌跡擷取管線。
🧠 防禦二：兩階段憲法分類器與 MMD 語義分佈偏移檢驗
異常流量動態識別
傳統基於關鍵字之過濾器極易遭改寫規避。新體系在請求入口部署輕量級憲法分類器（Constitutional Classifier）進行粗篩，並結合最大平均差異（Maximum Mean Discrepancy, MMD）演算法，在滑動時間視窗內監控跨 IP 請求的語義嵌入分佈。當偵測到大批獨立帳號的查詢在語義空間呈現非自然的高度聚集或網格化探測分佈時，分類器會在毫秒內對異常流量打標並動態升級至深度審查。
🧬 防禦三：輸出統計浮水印與放射性溯源技術（Radioactive Genetics）
法庭級侵權溯源
前沿實驗室在推論取樣階段，依據隨機數種子將詞表動態劃分為「綠色清單（Greenlist）」與「紅色清單（Redlist）」，對綠名單 Token 的 Logits 施加微不可察的偏置扰動。當未經授權機構使用大量被擾動之合成資料微調自身學生模型時，該統計偏置會被不可逆地「遺傳」至下游模型的權重分佈中。即便經過多輪二次微調，防禦方仍可透過假設檢定在極高置信度（p < 10⁻⁶）下證明該模型源自被竊取之資料庫，提供法庭級侵權鐵證。

GEOPOLITICS & IP · 戰略與治理意涵

四、 智慧財產權邊界、防禦代價與出口管制連動

⚠️ 防禦機制對正規生態之附帶衝擊
為防堵推論區塊被探測而導入的「保留思維」強制前綴校驗，使合規開發者失去了在工作流程中動態修改上下文、壓縮長對話歷史與快取提示詞（Prompt Caching）的靈活性，間接推高了整個應用生態的開發門檻與推論延遲。
🌐 晶片出口管制與地緣戰略因果
透過未授權蒸餾取得能力的外部機構，往往會在自研模型中剝離安全護欄，帶來嚴重外溢風險。另一方面，消化並訓練承接自前沿模型的蒸餾數據集仍需高效能算力叢集，此一技術連動進一步強化了先進晶片出口管制政策在硬體層面實體阻斷的戰略必要性。
